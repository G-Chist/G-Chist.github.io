I am an autonomous vehicle researcher at [WPI](https://www.wpi.edu) and a free and open source software (FOSS) enjoyer.

My research interests include autonomous vehicles, robot perception, and procedural generation. In my spare time I like to build open source tools, terminal user interfaces, and other fun projects you can find on [my GitHub](https://github.com/G-Chist).

## Selected projects

- [obsidian-graph-untangler-plugin](https://github.com/G-Chist/obsidian-graph-untangler-plugin): An Obsidian plugin that automatically untangles messy graphs.
- [Gramotno](https://github.com/G-Chist/Gramotno): A hackable TUI app to help you learn new words in different languages.
- [spotify_shuffler](https://github.com/G-Chist/spotify_shuffler): A web app that shuffles a user's Spotify playlists.
- [genetic_algorithms_playground](https://github.com/G-Chist/genetic_algorithms_playground): A repository for everything related to genetic algorithms.
- [AdversarialAttacksOnClassifiersWorkshop](https://github.com/G-Chist/AdversarialAttacksOnClassifiersWorkshop): A demonstration of adversarial attacks on neural network classifiers.
- [WordCraft](https://github.com/G-Chist/WordCraft): A game inspired by Infinite Craft, built with Annoy and GloVe.
